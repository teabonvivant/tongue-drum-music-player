# 晴光同行（音源升級版）

[開啟二十首專輯](https://teabonvivant.github.io/tongue-drum-music-player/#playlist=daylight-realistic-v12)

本版更新原 daylight-album-v9 的二十首既有作品，保留各首長度、速度及空靈鼓旋律，並非二十首新作曲。原專輯繼續保留可聽。

每首空靈鼓主奏 WAV 及獨奏 MP3 與原版逐位元相同，主奏增益不變。整組伴奏平均 RMS 電平校準至主奏以下 10 dB；按實際樂句平滑調整伴奏，並檢查峰值及削波。沒有新增敲擊樂。

鋼琴沿用已接受的 Salamander 原始無損、多力度層方案；結他沿用 Meta Nylon Guitar 原始無損指彈及實際弦位。豎琴改用原始無損採樣及可用的中力度層；大提琴聲部使用更完整音域的 VSCO 弦樂組錄音，並非獨奏大提琴；長笛使用 VSCO 的長短音實錄。古箏、二胡沿用 DSK 採樣，洞簫、塤沿用原有錄音，改善取樣播放、包絡與混音。

部分管樂／二胡伴奏原編音域過低，本版只作整八度音域修正，保留原音級、節奏及起音拍點；詳見每首 performance_events。空靈鼓音高、節奏及音量完全不變。原 MIDI 保存為 original-score.mid（本機），不是本版伴奏音域修正後的 MIDI。

由自製採樣引擎渲染，並非完整 VST／SFZ 演奏模擬；房間殘響為程式模擬。技術核驗不代表聽感已獲用戶接受。各首原始分軌與完整記錄保留本機 songs/daylight-realistic-v12，公開歌曲 MP3、核驗記錄及音源署名存於此項目。封面沿用原專輯插圖。
